# Compatibility

These packages target **ETS2 1.60** and are currently a preview. Their in-game behavior and visual appearance have not yet been revalidated.

| Mod | Compatibility considerations |
| --- | --- |
| Regional GPS Minimal | Fixed official-map snapshot with 152 city overrides. Game, DLC, and custom-map updates may require a matching version. |
| VR Rain Streaks Subtle | Other weather or graphics mods replacing the same rain material can override it. |
| Quper Overrides | Requires the readable economy layout of Quper 1.60.4 and the original mod enabled below the addon. |
| AI Headlight Flash Consequence — Dynamic Flares | Requires Dynamic Flares v1.2. Only vehicles using the shared high-beam hookup are affected. |

Where two mods replace the same file, Mod Manager priority decides which definition is used. See [installation](INSTALLATION.md) and each mod's guide for load order.
